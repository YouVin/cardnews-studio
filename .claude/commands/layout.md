`docs/A00-teardown.md` 와 **원본 이미지**를 같이 봐라. 실제 배치를 옮겨야 한다.
`schemas/screens.schema.json` 규격을 따른다.

`specs/cards.json` 을 작성한다. 규칙:

- `canvas`는 카드뉴스 실제 비율에 맞춘다.
  인스타 정방형 1080x1080 / 세로형 1080x1350 / 링크드인·브런치 1200x900
- `screens` 배열의 항목 하나 = 카드 한 장. `id`는 `S01`부터, `name`은 카드의 역할
  (예: "후킹", "문제 제기", "해법", "CTA")
- `note`에는 **그 카드가 그 자리에 있는 이유**를 한 문장으로 적는다.
  이게 이 산출물의 핵심이다. 예쁜 그림이 아니라 판단의 기록이어야 한다
- `label`에는 실제 들어간 카피를 쓴다. 길면 앞 15자 + `…`
- 색·폰트·이미지 스타일은 정하지 마라. 와이어프레임이다

다 쓰고 카드 수와 스키마 검증 결과를 보고하고 멈춰라.
