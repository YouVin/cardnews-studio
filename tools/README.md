# preview.js — 피그마 없이 검증하기

`figma-plugin/code.js` 를 그대로 실행해서 배치를 검사합니다.
피그마를 열어 눈으로 확인하는 대신, 문제를 숫자로 잡습니다.

```bash
node tools/preview.js examples/library/product.json out.svg
```

## 잡아내는 것

| 항목 | 기준 |
|---|---|
| 아래로 넘침 | 요소가 프레임 밖으로 나감 |
| 하단 여백 과다 | 22% 이상 비어 있음 (마지막 블록이 flex면 의도로 보고 넘어감) |
| 오른쪽 넘침 | 가로로 삐져나감 |
| 텍스트 겹침 | 글자 상자끼리 8px 이상 포개짐 |
| 가장자리 침범 | 프레임 경계 24px 안쪽에 들어옴 |
| 글자 너무 작음 | 22px 미만으로 축소된 문구 |
| 엔진 경고 | 자동 축소가 15% 이상 걸린 카드 |

두 번째 인자를 주면 SVG 미리보기도 함께 만듭니다.
브라우저나 피그마에서 열어 눈으로 확인할 수 있습니다.

## 정확도

텍스트 높이는 추정값입니다. 한글은 글자당 1em, 영문·숫자는 0.55~0.62em으로 잡습니다.
실제 피그마보다 한두 줄 차이가 날 수 있으므로, **넘침이 20px 이내면 통과로 봐도 됩니다.**
반대로 여기서 넘치면 피그마에서는 거의 확실히 넘칩니다.

## 새 JSON을 검증하는 흐름

```
JSON 수정 → node tools/preview.js spec.json out.svg → 문제 0건 → 플러그인에 붙여넣기
```
