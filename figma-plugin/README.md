# 카드뉴스 기획 스튜디오 (피그마 플러그인)

제품 설명 텍스트를 넣으면 피그마 안에서 세 가지가 한 번에 나옵니다.

1. **기획 문서 보드** — 타겟·인식수준·핵심메시지·배경·문제정의·소구점·측정지표
2. **와이어프레임** — 회색조 구조 검증용. 각 프레임 아래에 "이 카드가 여기 있는 이유" 캡션
3. **카드뉴스 시안** — 브랜드 컬러와 타이포가 적용된 실제 카드

## 설치

1. 피그마 **데스크톱 앱** 실행 (브라우저 버전은 로컬 플러그인 불가)
2. `Plugins` → `Development` → `Import plugin from manifest…`
3. `figma-plugin/manifest.json` 선택

## 무료로 쓰는 법

### 방법 1 — 직접 붙여넣기 (기본값, 완전 무료)

API 키가 아예 필요 없습니다. 이미 쓰고 있는 claude.ai나 ChatGPT를 그대로 씁니다.

1. 제공자를 `직접 붙여넣기 (무료)`로 둔다
2. 제품 설명 붙여넣고 **프롬프트 만들기**
3. 나온 프롬프트를 전체 복사 → claude.ai 대화창에 붙여넣기
4. 돌아온 JSON을 복사 → 플러그인의 `결과 붙여넣기` 칸에 → **JSON 확인**
5. **피그마에 생성**

손이 한 번 더 가지만 비용이 0원이고, 대화창에서 "3번 카드 더 세게"처럼
이어서 다듬을 수 있어서 결과가 더 좋을 때가 많습니다.

### 방법 2 — Gemini 무료 한도

`aistudio.google.com`에서 API 키 발급. 카드 등록이 필요 없습니다.
Flash 계열 모델은 무료 한도가 있고, 이 플러그인은 호출량이 적어서 한도에 잘 안 걸립니다.

주의: 무료 한도에서는 입력한 내용이 구글의 모델 개선에 쓰일 수 있습니다.
클라이언트 자료를 다룰 때는 방법 1을 쓰거나 유료 전환을 고려하세요.
한도와 조건은 자주 바뀌므로 발급받을 때 AI Studio에서 확인하세요.

## 준비물 (유료 자동 모드를 쓸 때만)

**API 키가 필요합니다.** 플러그인에 키를 심어서 배포하면 남이 내 크레딧을 쓰게 되므로,
각자 자기 키를 넣는 구조입니다. 키는 피그마 로컬 저장소(`clientStorage`)에만 저장되고
파일을 공유해도 따라가지 않습니다.

| 제공자 | 키 발급 | 기본 모델 |
|---|---|---|
| Claude | console.anthropic.com | `claude-sonnet-5` |
| Gemini | aistudio.google.com | `gemini-2.5-flash` |

## 비용

호출 1회에 입력 약 2,000 토큰 / 출력 약 3,000 토큰이 듭니다.
카드 수를 늘리면 출력이 비례해서 늘어납니다.

| 모델 | 1회 대략 | $5로 |
|---|---|---|
| `claude-sonnet-5` | 40~60원 | 100회 안팎 |
| `claude-haiku-4-5` | 20~30원 | 200회 이상 |

- 신규 Anthropic 계정에는 $5 트라이얼 크레딧이 붙습니다
- 한글은 영어보다 토큰을 많이 먹으므로 위 수치는 넉넉하게 잡은 값입니다
- 요금은 바뀔 수 있으니 실제 단가는 anthropic.com/pricing 에서 확인하세요

## 사용 — 3단계

터미널이 필요 없습니다. 플러그인 안에서 끝납니다.

**1단계 · 자료 넣기**
`notes.txt` 같은 파일을 끌어놓거나 내용을 직접 붙여넣습니다.
카드 수, 톤(제품/정보/인사이트), 상황(이미 만든 것/앞으로 만들 것)을 고릅니다.

**2단계 · 기획하기**
기본은 `claude.ai에 붙여넣기 (무료)` 입니다.
`프롬프트 복사하기` → claude.ai 대화창에 붙여넣기 → 돌아온 JSON을 아래 칸에 → `불러오기`.

불러오면 카드 목록이 뜨고 **글자 수를 초과한 카드는 빨갛게 표시**됩니다.
피그마에서 잘리기 전에 여기서 잡습니다.

API 키가 있으면 제공자를 바꿔 버튼 하나로 생성할 수도 있습니다.

**3단계 · 디자인**
브랜드명·핸들·컬러 3종·비율을 넣고 만들 보드를 고른 뒤 생성합니다.
생성 후 **넘치거나 여백이 과한 카드가 있으면 하단에 목록으로 알려줍니다.**

## 예전 방식

1. **설정** 열고 API 키, 브랜드명, 핸들, 브랜드 컬러, 비율, 카드 수 입력 (최초 1회)
2. 제품 설명이나 인스타 캡션을 그대로 붙여넣기
3. **기획 생성** — 20~40초
4. 카드 구성 확인. 마음에 안 들면 `결과 직접 수정 (JSON)`에서 고치거나 **다시 생성**
5. 만들 보드를 체크하고 **피그마에 생성**

3번과 5번 사이에 검토 단계가 있는 게 핵심입니다.
카피 초안은 AI가, 브랜드 톤 판단은 사람이 합니다.

## 05 카드뉴스 시안

레이아웃 5종을 브랜드 컬러로 그립니다. `layout` 값에 따라 구성이 달라집니다.

| layout | 구성 |
|---|---|
| `cover` | 사진 전면 + 하단 그라디언트 + 포인트 컬러 라벨 |
| `list` | 상단 사진(어둡게) + 헤드라인 + 하단 체크 리스트 카드 |
| `table` | 연한 배경 + 좌측 제품 컷 + 우측 흰 표 카드 |
| `cta` | 상단 검정 바 + 큰 슬로건 + 하단 포인트 컬러 바 |
| `text` | 기본 본문 + 하단 이미지 |

**사진은 직접 넣습니다.** 회색 영역의 이름이 `사진 · 표지` 처럼 붙어 있으니,
피그마에서 이미지 파일을 그 위로 끌어놓으면 그대로 채워집니다.

색은 두 개만 씁니다. 메인 컬러(구조), 포인트 컬러(강조).
세 번째 색을 넣고 싶어지면 대개 위계가 정리되지 않은 것입니다.

## 못 하는 것

- **이미지 생성 불가.** 플러그인은 도형과 텍스트만 만듭니다.
  사진 자리는 "여기에 사진을 넣으세요" 프레임으로 잡혀 있으니 직접 끌어다 넣으세요
- **폰트는 컴퓨터에 설치된 것만.** Pretendard → Noto Sans KR → Apple SD Gothic Neo →
  맑은 고딕 순으로 찾아서 씁니다. 하나도 없으면 Inter로 떨어지고 한글이 깨집니다
- **실측 지표는 채우지 않습니다.** 게시 전이니 값이 없는 게 맞습니다. 게시 후 직접 채우세요

## 지어내기 방지

시스템 프롬프트에 이 규칙들이 박혀 있습니다.

- 원문에 없는 수치·인증 기관명·효능·가격·후기를 만들지 않는다
- 원문이 "글로벌 인증"이라고만 했으면 특정 인증명을 붙이지 않는다
- 한 카드에 성격이 다른 메시지를 섞지 않는다
- 문제를 꺼내기 전에 해법부터 말하지 않는다

그래도 완벽하진 않습니다. **생성된 카피에 숫자나 기관명이 보이면 원문에 있는지 반드시 대조하세요.**
