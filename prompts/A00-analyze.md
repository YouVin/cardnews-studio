# A00. 카드뉴스 해부

## 출력 구조 (docs/A00-teardown.md)

### 1. 개요
| 항목 | 내용 |
|---|---|
| 브랜드/제품 | |
| 채널 | 인스타그램 / 링크드인 / 브런치 등 |
| 카드 수 | |
| 비율 | 1:1 / 4:5 / 기타 |
| 한 줄 목적 | 이 세트가 독자에게 시키려는 단 하나의 행동 |

### 2. 카드별 해부
카드 한 장당 아래를 반복한다.

**카드 N — 역할명**
| 항목 | 내용 |
|---|---|
| 역할 | 후킹 / 문제 제기 / 근거 / 해법 / 신뢰 / CTA 중 하나 |
| 카피 | 실제 들어간 문구 그대로 |
| 시각 요소 | 이미지, 도형, 아이콘의 배치 |
| 시선 흐름 | 독자의 눈이 어디서 시작해 어디로 가는가 |
| 이 카드가 없으면 | 뺐을 때 무엇이 무너지는지 |

마지막 항목이 핵심이다. 답이 "별로 안 무너진다"면 그렇게 적어라.
그게 다음 세트에서 개선할 지점이 된다.

### 3. 전체 흐름
카드 순서를 독자의 심리 이동으로 설명한다.
`관심 없음 → 어? → 나도 그런데 → 그래서 뭔데 → 해볼까` 같은 식.

### 4. 반복 요소
모든 카드에 공통으로 들어간 것. 로고 위치, 여백, 타이포 크기 단계, 컬러 사용 규칙.
브랜드 일관성을 어떻게 유지했는지가 여기서 드러난다.

### 5. 읽어낸 것 vs 해석한 것
| 항목 | 근거 |
|---|---|
표시는 `[카드뉴스]` `[메모]` `[추정]` 셋 중 하나.

### 6. 확인 필요
사용자에게 물어야 할 질문 3개 이하.
