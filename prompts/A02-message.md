# A02. 메시지 설계서

목적: **카피를 감으로 쓴 게 아니라 구조로 설계했다는 것을 보이는 문서.**

## 출력 구조 (docs/A02-message.md)

### 1. 설계 프레임
사용한 프레임을 명시하고 각 항목을 채운다.

**P.D.A.**
| | 내용 |
|---|---|
| Persona | 누구에게 말하는가 |
| Desire | 그들이 원하는 것 |
| Awareness | 문제를 얼마나 아는가 |

### 2. 선택한 앵글
| 앵글 | 정의 | 이번에 썼는가 | 이유 |
|---|---|---|---|
| 공감 | "나도 그랬어요" | | |
| 두려움 | "안 하면 놓칩니다" | | |
| 혜택 | "3배 빨라집니다" | | |
| 편의 | "5분이면 됩니다" | | |
| 권위 | "N년째 쓰고 있습니다" | | |

**안 쓴 앵글에도 이유를 적어라.** 왜 안 썼는지 설명할 수 있는 게 설계의 증거다.

### 3. 카드별 카피 설계
| 카드 | 역할 | 실제 카피 | 이 위치인 이유 |
|---|---|---|---|

### 4. 심리 이동 경로
독자의 상태가 카드를 넘기며 어떻게 변하는지.
Mermaid `flowchart LR` 로 그린다. 노드는 독자의 심리 상태로 적는다.

### 5. 구조상 약한 지점
논리로 설명이 안 되는 카드, 흐름이 끊기는 구간.
없으면 "없음"이라고 쓰지 말고 다시 한 번 검토해라. 보통 하나는 있다.

### 6. 다음 세트에 적용할 것
이 분석에서 나온 실행 가능한 개선안 2~3개.
