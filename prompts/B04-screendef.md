# B04. 화면정의서

화면 단위로 "이 화면에서 무슨 일이 일어나는가"를 정의한다.
기능명세서(B03)가 "무엇을 만드는가"라면, 이 문서는 "그래서 화면에서 어떻게 보이는가"다.

## 출력 구조 (docs/B04-screendef.md)

IA의 전체 페이지 목록에 있는 **모든 화면**에 대해 아래를 반복한다.
하나도 빠뜨리지 마라.

---

## S01. 화면명

| 항목 | 내용 |
|---|---|
| 그룹 | |
| 관련 기능 | B03의 기능 번호 (예: 1.1, 2.3) |
| 목적 | 한 문장 |
| 진입 | 어디서 들어오는가 |
| 이탈 | 어디로 나가는가 |
| 권한 | 비로그인 / 로그인 / 관리자 |

**화면 구성**
| 영역 | 요소 | 내용 | 비고 |
|---|---|---|---|
| 상단 | 네비게이션 | 뒤로가기 + 타이틀 | |
| 본문 | | | |
| 하단 | | | |

**인터랙션**
| # | 사용자 행동 | 조건 | 시스템 반응 | 이동 |
|---|---|---|---|---|

**화면 상태**
| 상태 | 발생 조건 | 화면 표시 | 다음 행동 유도 |
|---|---|---|---|
| 기본 | | | |
| 로딩 | | | |
| 빈 상태 | | | |
| 오류 | | | |
| 권한 없음 | | | |

빈 상태와 오류는 반드시 채운다. "없음"이라고 쓰지 마라.
**빈 화면에 무슨 문구를 띄우고 다음 행동을 어떻게 유도할지까지 적는다.**
빈 화면은 분위기가 아니라 방향을 주는 자리다.

**입력 검증**
입력 필드가 있는 화면만. 없으면 이 항목을 생략한다.
| 필드 | 필수 | 제약 | 오류 문구 |
|---|---|---|---|

오류 문구는 사과하지 않고, 무엇이 잘못됐고 어떻게 고치는지 알려준다.
"오류가 발생했습니다" 같은 문구를 쓰지 마라.
