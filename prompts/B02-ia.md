# B02. IA — 사이트맵과 전체 페이지 목록

## 출력 구조 (docs/B02-ia.md)

### 1. 사이트맵
Mermaid `flowchart LR` 로 전체 구조를 그린다.
**영역(그룹) 단위로 subgraph를 나눈다.** 예: 인증·온보딩 / 메인 / 예약·검색 / 관리자·설정

```
flowchart LR
  subgraph 인증·온보딩
    A1[랜딩] --> A2[로그인]
    A1 --> A3[회원가입]
  end
  subgraph 메인
    B1[홈] --> B2[검색]
  end
  A2 --> B1
```

시나리오가 아니라 **구조**를 그리는 것이다. 조건 분기는 여기 넣지 않는다.

### 2. 전체 페이지 목록
| No | ID | 그룹 | 페이지명 | 목적 | 진입 경로 | 우선순위 |
|---|---|---|---|---|---|---|
| 1 | S01 | 인증 | 로그인 | | | P0 |

- `No`는 1부터 연속. 그룹이 바뀌어도 이어서 매긴다
- `ID`는 `S01`부터. 이후 모든 문서와 `specs/screens.json`에서 동일하게 유지
- `그룹`은 사이트맵의 subgraph 이름과 정확히 일치시킨다
- 페이지가 8개 미만이면 서비스가 너무 얇은 것이다. 누락된 화면을 다시 검토하라
  (약관, 검색 결과 없음, 완료, 오류 페이지는 자주 빠진다)
