# 레퍼런스 라이브러리

`/studio` 와 `/plan` 은 여기 있는 JSON을 **톤 레퍼런스로 읽는다.**
레퍼런스 한 장이 붙으면 결과의 톤이 확 잡힌다. 설명 열 줄보다 예시 하나가 낫다.

## 쓰는 법

새 작업의 톤이 어느 쪽인지 정해서 명령어에 넘긴다.

```
/plan 5 --ref info
/studio --ref product
```

지정하지 않으면 전부 읽고 상황에 맞는 쪽을 참고한다.

## 파일

| 파일 | 성격 | 언제 쓰나 |
|---|---|---|
| `product.json` | 제품 소개형 | 판매·홍보. 사진이 주인공 |
| `info.json` | 정보 전달형 | 용어 정리, 개념 비교. 표와 비교가 주인공 |

## 추가하는 법

잘 나온 결과물의 `specs/studio.json` 을 여기 복사하고 파일명을 성격으로 붙인다.
개인정보나 클라이언트 비공개 자료가 들어간 건 넣지 마라.

**3~5개면 충분하다.** 그 이상 쌓으면 오히려 톤이 흐려진다.
비슷한 게 두 개 있으면 더 나은 쪽만 남긴다.
